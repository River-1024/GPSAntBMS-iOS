## 自动化验证

GitHub Actions 使用标准 macOS `xcode-27` runner，并依次执行：

1. 校验 Xcode、Swift 和 iOS 27 SDK。
2. 校验 Liquid Glass 集成约束。
3. 安装 XcodeGen 并生成工程。
4. 运行 `swift test` 纯领域测试。
5. 运行模拟器单元测试和 UI 冒烟测试。
6. 构建 Release 设备包并生成未签名 IPA。
7. 校验 IPA 目录、可执行文件和签名材料边界。

2026-08-16，公开仓库已成功完成上述完整 CI，并上传通过结构校验的未签名 IPA Artifact。Windows 环境只能执行 Git、文本、YAML、plist 和敏感信息静态检查，不能替代 Xcode 构建。

## 已知限制

- 未签名 IPA 不能直接安装或发布，需要用户自行签名。
- 行车记录依赖真实摄像头、麦克风、编码器、磁盘和热状态，模拟器不能完成验收。
- 行程历史保存原始 GPS 轨迹；分发前需要根据实际分发渠道确认最终隐私披露和保留策略。
- 屏幕方向偏好、Dynamic Type、VoiceOver 和高对比度仍需要真机/模拟器专项复核。
